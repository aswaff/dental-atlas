# Dental Terminology Atlas

An interactive 3D study atlas for dental assisting: dental and head-and-neck anatomy, the operatory and instruments, infection control and sterilization, patient care and dental radiography. Each lesson has quick checks, a "Things best to remember" summary, competency checklists and review quizzes.

Open `index.html` in a browser, or view it on GitHub Pages.

The whole site is one HTML file. It loads three.js from cdnjs and fonts from Google Fonts. Competency checkmarks are saved in your browser only.
